# IronWill Android 0.1

这是可自行安装的原生 Android 第一版。使用 Java + 系统 UI，运行时没有第三方库，也没有云端模型。所有输入默认空白。契约、主线、处境、后果、红线应用和最近 200 条记录保存在应用私有存储。

## 已实现

- 用你自己的原话保存承诺、现实处境、拖延后果和当前主线；提醒可引用这些原文，不编造后果。
- 手动开始、继续、暂停、结束执行周期；不按午夜重置，不安排固定作息，不验收成果。
- 从可启动应用列表选择红线应用，也可手动输入包名。
- 连续处于红线应用约 60 秒后发送提醒；切走、锁屏、未知观察或暂缓提醒都会停止累计这次停留。
- 通知中的“返回主线”暂停检查 2 分钟；“值得”“喘息”各暂缓 15 分钟。普通通知可由配对手表镜像。
- 使用情况访问为基础感知；可选无障碍只读窗口所属包名，不读取页面树、标题、消息、密码、按键或截图。
- Android 13+ 通知权限与渠道状态检查；监测必须在应用内主动开始。
- 电脑可选 HTTPS 局域网配对，固定证书 SHA-256 指纹 + bearer token；状态心跳、30 秒提醒路由申请、手动导入电脑 goal/oath、手动发电脑选择。没有配对也能独立工作。
- 有明确确认的单次系统锁屏测试。日常提醒不自动锁屏、复锁、卸载或自删除。

## 安装后开始

1. 安装 `IronWill-Android-0.1.apk` 并打开。
2. 填写承诺与当前主线；处境、后果可选，仅保留在手机。
3. 选择至少一个红线应用。
4. 打开“通知权限与提醒测试”，允许通知并确认渠道开启。
5. 打开“活动感知权限”，选择使用情况访问；或自行开启可选无障碍。系统的授权操作必须由你执行。
6. 点击“开始 / 继续这一轮”，再切到红线应用持续约一分钟。监测运行时有状态通知。

系统可能停止或延迟后台工作。重新打开应用会显示真实状态；如果显示“监测未运行”，点击继续。第一版没有开机自动恢复入口。未响应通知不算违约；没有通知已读证明。

## 可选电脑配对

先在 Windows 端主动启用局域网服务，手机与电脑处于可互通网络。手机输入电脑界面提供的 HTTPS 地址、64 位 SHA-256 证书指纹、令牌，核对指纹后点击“验证并保存”。应用不接受明文 HTTP、不跳过证书指纹校验、不跟随重定向。断开配对会移除本地令牌。

“导入电脑任务”先展示 goal/oath，确认后才复制，不自动开始手机周期。处境和后果不通过 relay 传输。发送电脑选择是明确单独操作；手机通知按钮只处理手机当前提醒。V1 不宣称两端惩罚计数同步；断网时本地轻提醒可能与电脑重复。

## 可重复构建

需要 Windows、JDK 11 或更高、Android SDK Platform 35、Build Tools 34.0.0（含 aapt、d8、zipalign、apksigner）。脚本只读取 SDK，不修改 Unity 或用户手机。

在此目录运行：

```powershell
pwsh -File .\build.ps1 -AndroidSdk "C:\path\to\Android\SDK" -JavaHome "C:\path\to\JDK"
pwsh -File .\test.ps1 -JavaHome "C:\path\to\JDK"
```

也可以设置 `ANDROID_SDK_ROOT` 与 `JAVA_HOME` 后直接运行 `build.ps1`。脚本还会尝试本机已有的 Unity AndroidPlayer SDK，但其路径不是唯一选项。输出为 `build/IronWill-Android-0.1.apk`，脚本运行 apksigner 验证并输出 SHA-256。

构建脚本在 `build/ironwill-development.jks` 创建公开密码的**开发签名**，用于个人测试；保留该文件可在当前安装上覆盖升级。它不适合商店正式发行，也不要用于其他产品。需要正式发行时换成私有发布签名并设计迁移；修改签名后 Android 通常不能直接覆盖已有安装。脚本不依赖 Gradle 网络下载。Gradle 工程文件供 IDE 使用，尚未单独执行 Gradle 构建验证。

## 验证范围

- 已用实际 SDK 35 完成 Java 编译、资源打包、DEX 转换、APK 签名并验证签名。
- 纯 JVM 核心测试涵盖 26 项提醒边界与 relay HTTP 状态码断言，含桌面动作的 202 排队响应。
- 尚未执行手机或模拟器上的安装、界面、后台保活、实际通知、锁屏、Wear 转发验收；这些不能由编译替代。
- 包级识别有 ROM/多窗口/使用情况访问延迟差异。无障碍事件不是物理触摸证明；后台服务不保证永远存活。
- 当前 `minSdk=28`、`targetSdk=35`，为自行安装版本。2026-10-09 核查的 Play 手机新应用目标要求为 API 36；商店发布前必须升级目标版本并重跑平台与政策验证。
